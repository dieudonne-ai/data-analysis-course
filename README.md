# Data Analysis Course

A hands-on course in data analysis, written in English, with worked examples in Python.
New lessons are added regularly, one commit per lesson.

## Setup

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

Each module has a `README.md` (the lesson) and an `examples/` folder with runnable scripts.
