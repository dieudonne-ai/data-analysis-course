# Module 11 — Time Series Analysis (bonus)

A **time series** is data ordered in time (monthly revenue, daily visitors...). Order matters, so
we cannot treat rows as independent or shuffle them. We use `data/monthly_sales.csv`
(36 months, generated by [`examples/make_data.py`](examples/make_data.py)).
Workflow diagram: [`diagrams/workflow.pdf`](diagrams/workflow.pdf)

## 1. Parse dates and plot first
```python
df = pd.read_csv("data/monthly_sales.csv", parse_dates=["month"])
s = df.set_index("month")["revenue"]      # a Series indexed by date
```
Always plot before modelling: look for a rising line (trend) and repeating waves (seasonality).

## 2. Trend with a moving average
`s.rolling(12, center=True).mean()` averages 12 months, so the yearly wave cancels and the trend remains.
Example: the 12-month average goes 113 (Jul 2023) → 141 (Jul 2024) → 172 (Jul 2025).
A linear fit gives `revenue = 98.4 + 2.49 * month_index`: about **+2.5 per month**.
Diagram: [`diagrams/trend_ma.pdf`](diagrams/trend_ma.pdf)

## 3. Seasonality and decomposition
Remove the trend, then average by calendar month. Here sales are **+13.6 in December** and **−13.1 in July**
compared with the trend. What is left is the **residual** (std 2.9) = noise.
`observed = trend + seasonal + residual`
Diagram: [`diagrams/decomposition.pdf`](diagrams/decomposition.pdf)

## 4. Forecasting honestly
Split **by time** (train on the first 30 months, test on the last 6), never randomly.
Compare with a naive baseline ("next month = last month"):

| Model | MAE (last 6 months) |
|-------|--------------------|
| Naive (last value) | 20.73 |
| Trend + season | 2.42 |

If your model can't beat the naive baseline, it is not useful.
Diagram: [`diagrams/forecast.pdf`](diagrams/forecast.pdf)

## Exercises
1. Change the window to 3 and 6. What happens to the smoothness of the moving average?
2. Add a 7th held-out month and check whether the MAE changes much.
3. Replace the linear trend with a quadratic one (`np.polyfit(t, y, 2)`). Does test MAE improve?
4. Use `s.pct_change(12)` to compute year-over-year growth.
